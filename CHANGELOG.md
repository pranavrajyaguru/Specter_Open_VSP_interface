# Changelog

## 1.0.0 — Wing aerodynamic studies

- Parametric five-station Model A wing with provisional NACA 2412 sections.
- Repeatable VSPAERO VLM angle-of-attack sweep.
- Three-level mesh-resolution sensitivity study.
- Three-variant wingtip-chord geometry study.
- Automated CSV tables and optional matplotlib plots.
- Numerical unit tests and documented limitations.

Validation status: The preceding study implementation completed aerodynamic runs on a local OpenVSP installation. The reorganized release requires a final local solver run. Mesh independence of induced drag was not established.
